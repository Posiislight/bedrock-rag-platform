Request flows

Two paths: answer now, or answer later

Synchronous RAG returns cited answers in one call. The async path returns a job id immediately and lets SQS handle retries and dead-lettering.

RAG query, synchronous

POST /v1/rag/query
  1. AuthenticateX-API-Key checked against the Secrets Manager value
  2. Embed the questionTitan Text Embeddings v2 via Bedrock
  3. Search the indexload vectors.npy + chunks.json from S3, cosine top-k (default 4)
  4. Build a numbered promptsystem prompt: answer only from passages, cite [n], say "don't know" otherwise
  5. Converse callchat model returns text plus token usage
  6. Resolve citationsonly [n] that map to real passages are kept, with source, chunk, score, snippet
  7. Emit metricslatency, tokens, CostUSD to CloudWatch (batched)

Async job lifecycle

POST /v1/jobs returns 202 {job_id, status: "queued"}
Failure never deletes the message, so retry logic lives in SQS rather than in custom code. A DLQ alarm fires on the first dead-lettered job.
